# Демонстрация интервального кодирования

`range_coding_demo.py` — учебная программа на Python 3 (без зависимостей),
показывающая, как работает интервальное (арифметическое) кодирование.

1. **Точная арифметика** (`fractions.Fraction`): пошагово видно, как интервал
   `[0, 1)` сужается до подынтервала каждого символа, какие цифры «определились»,
   и как по одному двоичному числу из итогового интервала восстанавливается сообщение.
2. **Целочисленный 32-битный кодер** (в стиле Субботина / LZMA): нормализация
   по байтам, обработка переноса, кодирование в байты и обратное декодирование.
3. **Сравнение** размера результата с равномерным кодом и границей Шеннона `n·H`.

## Графическое приложение

`range_coding_gui.py` — оконное приложение (tkinter). Вкладки:

| Вкладка | Что показывает |
|---|---|
| **Кодирование** | Таблица шагов: символ (каждый своим цветом), p, Q, новые границы l, h; просмотр по шагам (⏮ ◀ ▶ ⏭) с вычислениями текущего шага |
| **Декодирование** | Таблица шагов: текущий интервал, v = (x − l)/(h − l), интервал символа и декодированный символ; можно ввести свой код (двоичный или десятичный) |
| **Пошаговый отчёт** | Формулы в виде «как в Word», таблицы, сравнение; флажок «Подробные шаги» добавляет арифметику каждого шага. Сохранение в **.docx** с редактируемыми формулами Word |
| **Справка** | Как пользоваться программой |

Оформление отчёта — по ГОСТ 7.32-2017 / ГОСТ 2.105-2019 (нумерация разделов,
формулы с номером в скобках справа, «где …» под формулой, «Таблица N — …»,
десятичная запятая; в .docx — поля 30/15/20/20 мм,
Times New Roman 14, интервал 1,5, абзацный отступ 1,25 см, номера страниц).
Интерфейс — с учётом ГОСТ Р ИСО 9241-110 (принципы организации диалога).

```bash
pip install -r requirements.txt     # python-docx (сохранение отчёта в Word)
python3 range_coding_gui.py
```

Модули: `gui_analysis.py` (расчёт), `gui_diagrams.py` (пошаговые таблицы),
`gui_report.py` (отчёт), `gui_mathdraw.py` (отрисовка формул), `gui_formula.py` (числа),
`gui_export.py` + `gui_omml.py` (экспорт в Word).

Сборка исполняемого файла (PyInstaller):

* Windows: `build_exe.bat` → `dist\RangeCodingDemo.exe`
* Linux: `./build_linux.sh` → `dist/RangeCodingDemo`
  (нужен `python3-tk`; запуск: `chmod +x RangeCodingDemo && ./RangeCodingDemo`)

## Запуск консольной версии

```bash
python3 range_coding_demo.py                    # пример по умолчанию
python3 range_coding_demo.py "КОЛОКОЛ"          # своё сообщение
python3 range_coding_demo.py -f text.txt        # сообщение из файла
python3 range_coding_demo.py abracadabra --no-steps
```
