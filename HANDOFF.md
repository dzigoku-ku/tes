# Передача проекта: демонстрация интервального кодирования

Этот файл — краткое описание состояния проекта для того, кто продолжает работу
(человека или новой сессии Claude). Достаточно дать его прочитать вместе с кодом.

## Что это

Учебная программа, показывающая интервальное (арифметическое) кодирование.

| Файл | Назначение |
|---|---|
| `range_coding_demo.py` | Ядро и консольная версия: модель частот, точный расчёт на дробях, 32-битный кодер (стиль LZMA) |
| `range_coding_gui.py` | Главное окно (tkinter): ввод сообщения, сводка «Результат», вкладки, меню, справка |
| `gui_analysis.py` | Полный расчёт для интерфейса (шаги кодирования/декодирования, трассировка 32-битного кодера) |
| `gui_diagrams.py` | Вкладки «Кодирование» и «Декодирование»: пошаговые таблицы, каждый символ своим цветом |
| `gui_report.py` | Вкладка «Пошаговый отчёт» (ГОСТ 7.32/2.105), флажок «Подробные шаги» — арифметика каждого шага |
| `gui_mathdraw.py` | Отрисовка формул на tk.Canvas (дроби, индексы, суммы, скобки) без внешних библиотек |
| `gui_omml.py` | Разбор TeX-подмножества формул; преобразование в формулы Word (OMML) |
| `gui_export.py` | Сохранение отчёта в .docx (python-docx), поля/шрифт по ГОСТ 7.32, редактируемые формулы |
| `gui_formula.py` | Форматирование чисел (десятичная запятая) и символов |
| `tests/` | Модульные тесты: `python3 -m unittest discover -s tests -t .` |
| `build_linux.sh`, `build_exe.bat` | Сборка одного исполняемого файла PyInstaller (Linux / Windows) |
| `qt-app/` | Отдельный проект пользователя на Qt5/C++ (таблицы интервалов) + `build_appimage.sh` |

Зависимость интерфейса — только `python-docx` (`requirements.txt`).

## Решения, принятые по просьбам пользователя

1. Графики (схемы с отрезками) **убраны** со вкладок кодирования/декодирования;
   вместо них таблицы шагов, **буквы окрашены** (у каждого символа свой цвет).
2. Отчёт оформлен «как в Word»: формулы с номерами справа, «где …», «Таблица N — …»,
   десятичная запятая. Подробный режим показывает подставленные числа на каждом шаге.
3. Исполняемые файлы должны быть **одиночными файлами < 30 МБ** (лимит отправки
   в чат). Поэтому matplotlib/numpy убраны, формулы рисуются своим кодом.
4. Пользователь работает в **Linux** (и ему нужна также Windows-версия).

## Известные особенности

* PyInstaller-сборка: python-docx ищет шаблоны по пути `docx/parts/../templates`;
  `gui_export._fix_frozen_templates()` создаёт папку `docx/parts`, иначе сохранение
  в .docx падает в Linux-сборке. Сборку делать с `--collect-data docx`.
* Windows-exe собирался под Wine (Python 3.12 для Windows). Свежий numpy под Wine 9
  не работает — но numpy больше не используется.
* Формулы .docx проверялись в LibreOffice (нужен пакет LibreOffice Math); в самом
  Word не проверялись.
* Отправка на GitHub (`dzigoku-ku/chos`, ветка `claude/interval-encoding-demo-9tnx44`)
  не удалась: у Claude нет доступа к репозиторию (ошибка 403). Нужно подключить GitHub
  на https://claude.ai/connect-github и установить Claude GitHub App на репозиторий.

## Запуск

```bash
pip install -r requirements.txt
python3 range_coding_gui.py          # графическое приложение
python3 range_coding_demo.py "КОЛОКОЛ"   # консольная версия
```
